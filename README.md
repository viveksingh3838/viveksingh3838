### 🛠️ What I've been building

#### 🙏 Jaap — devotional Android app
A daily companion for mantra jaap, panchang and vrat, in **10 Indian languages**.
- Tap or **voice counting** — the phone listens for the mantra and counts it.
- **Panchang computed on the phone** from astronomy formulas: tithi, nakshatra, sunrise, Rahu kaal, Ekadashi paaran.
- **Janam kundli** (North & South charts, Vimshottari dasha), **kundli milan** (36 gunas) and a **vivah muhurat** finder.
- 146 vrat kathas, regional festival calendars, a home-screen widget, reminders and 183 automated tests.

`React Native` `Expo` `TypeScript` `astronomy-engine`

#### 🃏 Seep — real-time multiplayer card game
Online version of Seep (Sweep), the Indian fishing card game.
- **Server-authoritative** engine written as pure, immutable functions.
- Rooms and matchmaking over **socket.io**, with bots at four difficulty levels.
- Every move logged as JSONL to train a **neural-network bot**.
- Android app via Capacitor; CI/CD with GitHub Actions → AWS EC2 + PM2.

`React` `Node.js` `socket.io` `Capacitor` `Vitest`

#### 🏎️ Tiny Track Rivals — kart racer for Android
Portrait arcade racer built in **Unity 6 (URP)**.
- Story campaign: **8 worlds, 960 levels**, rival duels and boss races.
- Combat powers, drift-to-boost and a garage of hand-picked cars.
- Game rules in a pure C# layer — tests validate all 960 levels and bots race whole worlds headless.

`Unity 6` `C#` `URP` `Blender` `Python`

#### 🎬 FacelessTube — AI video automation platform
Runs faceless YouTube & Instagram channels end to end:

**Topic → Script → Voiceover → Stock media → Subtitles → Thumbnail → Assemble → Upload**

- Every step is a queued background job with retries.
- Content calendar, brand presets and an asset library per channel.
- A/B tests for titles and thumbnails, analytics sync and a quality score per video.

`Laravel` `PHP` `Vue` `TypeScript` `YouTube API`
